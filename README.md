# STAGE FINDER

## Projet Python - Data 

### Un programme qui recherche régulierement des offres de stage, les analyse selon tes critères, élimine les doublons et te présente les opportunités pertinentes dans un tableau de suivi

Le but : 
 - Recupérer automatiquement les offres d'emploi ou de stage depuis une API
 - Extraire les informations importantes 
 - Enregistrer ces informations dans une base de données
 - Afficher les offres dans un dashboard interactif
 - A terme, filtrer les offres pertinentes et automatiser leur récupéreration

Lancer le Dashboard : streamlit run Dashboard.py

Critères de recherche params :
 - motsCles ex: python
 - departement ex: 54
 - commune ex: 54395
 - distance ex: 20
 - typeContrat ex: CDD
